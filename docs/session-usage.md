# 컨텍스트와 계정 아일랜드

## 입력창의 컨텍스트 버튼

에이전트 입력창의 실행·중지 버튼 바로 왼쪽에 컨텍스트 사용률을 표시한다. 실행 중에는 같은 자리의 보내기 버튼이 중지 버튼으로 바뀌며, 종료 후 다시 보내기로 돌아온다. 다음 요청의 초안과 첨부는 유지된다. 원형 테두리는 사용률만큼 채워진다. 누르면 해당 실행 창의 모델, 워크스페이스, 최근 요청 시간, 토큰, 비용, CLI 세션 ID를 확인할 수 있다. 다른 실행 창으로 이동해도 열린 상세 창의 대상은 바뀌지 않는다.

상세 팝업은 내용 높이에 맞춰 줄어들고, 정보가 많은 경우에만 최대 높이에서 스크롤한다. 세션 ID는 기본으로 접혀 있으며 펼쳐서 확인할 수 있다. 내용을 펼치거나 접어도 팝업은 입력창의 컨텍스트 버튼에 붙어 있다.

- Claude: Mods의 `$.session.usage()`에서 직접 받은 컨텍스트·비용과 CLI가 보고하는 토큰을 사용한다. 최근 응답과 이번 실행, 대화 누적은 구분해 표시한다.
- Codex: 현재 `exec --json` 연결은 세션 누적 토큰을 제공하지만 현재 컨텍스트의 분자·한도를 제공하지 않는다. 누적 토큰을 컨텍스트로 환산하지 않는다.
- Gemini: 현재 `stream-json` 연결의 토큰 통계는 컨텍스트 점유율이 아니다. 실제 컨텍스트 측정치가 없으면 `—`로 표시한다.
- 미측정 값은 0으로 표시하지 않는다. 프로바이더 변경·새 대화 시작 시 이전 측정치를 지운다.

## 계정 아일랜드

화면의 **카메라 노치 양옆**과 앱 하단 상태 표시줄의 아일랜드는 **계정 사용 한도**를 표시한다. 대화 컨텍스트는 넣지 않는다. 아일랜드를 누르면 세션·주간 사용률, 초기화 시각과 제공되는 계정 정보를 확인할 수 있다.

카메라 배치는 `gbike-service-monitor/app/macos/Sources/AIMonitor/UsageIsland.swift`의 Amon 방식을 참고한다. `safeAreaInsets`와 좌우 `auxiliaryTopArea`로 카메라 폭을 계산하고 화면 맨 위에 붙인다. 카메라 가운데에는 글자를 그리지 않는다. 노치가 있는 화면을 우선하며, 그런 화면이 없으면 주 화면의 상단 중앙에 표시한다.

요약에는 사용 중인 프로바이더를 중복 없이 최대 두 개 표시한다. 한 프로바이더만 있으면 한 번만 표시한다. 활성 세션, 실행 중인 세션, 최근 요청 순으로 대표 계정을 고른다. 각 대표 계정에서 잔여량이 가장 적은 한도 두 개(사용률이 높은 두 개)를 선택하고, **세션 → 주간 → 기타** 순서로 표시한다. 숫자는 사용률이며 미확인은 `—`로 표시한다. 같은 프로바이더의 로컬·원격 계정을 합산하지 않는다. 클릭한 상세 화면에서는 호스트별 전체 계정을 계속 확인할 수 있다.

- 설정 → 계정 아일랜드에서 상단 표시를 끌 수 있다. 하단 표시는 유지된다.
- 열린 에이전트가 사용하는 로컬 프로바이더를 대상으로 60초마다 확인한다. 새로고침도 서버의 재시도 제한을 따른다.
- Claude는 기존 CLI 로그인으로 계정 한도를 읽고, 실행 중에는 Mods가 전달하는 한도도 사용한다. 인증 정보를 갱신하거나 덮어쓰지 않으며, 자동 조회로 인증 승인창을 띄우지 않는다. 직접 조회가 허용되지 않으면 실행 중 받은 값 또는 미확인 상태를 표시한다.
- Codex는 별도 app-server의 `account/read`와 `account/rateLimits/read`를 사용한다. 작업 스레드를 만들거나 모델을 호출하지 않는다.
- Gemini의 계정 한도 조회는 현재 연결에서 지원하지 않는다. 미지원 안내를 표시한다.
- 원격 컴퓨터의 세션은 그 컴퓨터에서 전달한 한도만 사용한다. 이 Mac의 로그인·계정 한도를 원격 세션에 적용하지 않는다.
- 마지막 정상값을 유지하는 경우 오래된 값임을 표시한다. 도구 출력·토큰 갱신이 계정 한도의 측정 시각을 갱신하지 않는다. 신원을 확인할 수 없는 직접 측정치에는 이전 계정명을 붙이지 않는다.

Claude의 유휴 계정 조회는 Amon과 같은 OAuth 내부 엔드포인트를 사용하므로 서버 변경이나 로그인 권한에 따라 제공되지 않을 수 있다. 그런 경우 임의의 수치를 만들지 않는다.

## 검증

모의 CLI·HTTP 응답으로 사용량 파싱, 인증 오류, 갱신 제한과 취소를 검사한다. 격리 프로필의 `--agent-smoke-test`는 실제 SwiftUI 창에서 컨텍스트 버튼의 정렬, 상세 창 갱신, 상단·하단 아일랜드 클릭과 원격 계정 분리를 확인한다. 이 진단은 실제 계정 인증 정보를 읽거나 모델·사용량 API를 호출하지 않는다.
