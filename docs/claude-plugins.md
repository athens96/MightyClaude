# 마이티 모드의 Claude·Codex 플러그인

Claude 또는 Codex 창에서 **마이티**를 선택한 뒤 상단의 퍼즐 아이콘을 누른다. 선택한 실행기의 플러그인만 표시하며, 창을 열거나 닫아도 그래프와 입력 중인 초안은 유지된다.

- **설치됨**: 플러그인 이름, 버전, 마켓플레이스, 설치 범위와 활성 상태를 확인한다. CLI가 보고한 오류·주의 사항도 표시한다.
- **마켓플레이스**: CLI가 제공하는 마켓플레이스의 플러그인을 이름·설명으로 검색하고 마켓플레이스별로 좁혀 본다. CLI가 제공한 설명과 버전을 함께 표시한다.
- **목록 새로고침**은 CLI에 설치 목록과 카탈로그를 다시 요청한다. **마켓플레이스 새로고침**은 선택한 마켓플레이스 또는 등록된 전체 마켓플레이스를 갱신한다. Codex는 등록된 Git 소스만 갱신한다.
- 설치 후 목록을 다시 조회한다. 실패하면 원인과 실행 상세를 표시하며 다시 시도할 수 있다.

## Claude

현재 Mac에 설치된 Claude Code 2.1.268 이상의 플러그인을 관리한다. 설치 범위는 기본 **이 워크스페이스·나만**(`local`)이다. **프로젝트 공유**(`project`) 또는 **모든 프로젝트**(`user`)도 선택할 수 있다. 프로젝트 공유는 프로젝트의 Claude 설정에 기록된다. 다음 Claude 요청부터 설치된 설정을 사용한다.

[공식 플러그인 CLI](https://code.claude.com/docs/en/plugins-reference)를 사용한다. `plugin list --json --available`과 `plugin marketplace list --json`으로 조회하고, `plugin install <plugin@marketplace> --scope <scope> --json`으로 설치한다. 조회는 저장된 카탈로그를 사용하며 마켓플레이스 갱신은 사용자가 직접 실행한다.

등록된 마켓플레이스가 없으면 [Claude의 마켓플레이스 추가 방법](https://code.claude.com/docs/en/discover-plugins#add-marketplaces)에 따라 먼저 등록한다.

## Codex

Codex CLI의 플러그인 명령을 사용하며, 0.153.4에서 확인한 JSON 형식을 지원한다. 설치된 플러그인과 CLI가 반환하는 카탈로그를 표시한다. 등록된 마켓플레이스와 Codex가 제공하는 원격 카탈로그의 플러그인을 모두 조회할 수 있다. 네트워크 오류 등으로 일부 목록을 읽지 못하면 CLI의 경고도 함께 표시한다.

Codex는 **사용자 · 모든 프로젝트**(`user`) 범위에 설치한다. 프로젝트·로컬 범위는 제공하지 않는다. 설치한 플러그인을 사용하려면 **새 Codex 세션**을 시작한다. 기존 대화를 재개하는 것만으로는 새 플러그인이 로드됐다고 보장할 수 없다. 앱 연결·로그인 등 추가 절차가 필요한 플러그인은 Codex가 안내하는 절차를 완료해야 한다.

`codex plugin list --available --json`과 `codex plugin marketplace list --json`으로 조회하고, `codex plugin add <plugin@marketplace> --json`으로 설치한다. 마켓플레이스 갱신에는 `codex plugin marketplace upgrade <name> --json`을 사용하며 등록된 Git 소스만 대상으로 한다. 로컬·기본 제공·원격 카탈로그의 현재 목록은 **목록 새로고침**으로 다시 조회한다. 해당 명령을 지원하지 않는 CLI에서는 업데이트 안내를 표시한다. 마켓플레이스를 추가하려면 Codex CLI에서 등록한 뒤 목록을 새로고침한다.

## 공통 지원 범위

원격 워크스페이스는 해당 컴퓨터의 MightyClaude에서 관리한다. 해당 실행기의 작업이나 CLI 업데이트·원격 공유가 진행 중이면 플러그인 변경을 막는다. 플러그인 변경 중에는 새 로컬 Claude·Codex 요청을 시작할 수 없다. 진행 중인 변경은 취소할 수 있지만, CLI가 이미 저장한 변경을 되돌리지는 않는다. 취소 후 목록을 다시 읽어 현재 상태를 확인한다.

앱은 실행기의 설정 파일을 직접 편집하지 않는다. 설치 목록의 활성 상태는 CLI의 설정 상태이며, 실행 중인 대화에 이미 로드됐다는 의미는 아니다. 새 마켓플레이스 등록·플러그인 삭제·활성화 전환은 이 화면에서 제공하지 않는다.
