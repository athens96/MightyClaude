# 마이티 모드의 Claude 플러그인

Claude 창에서 **마이티**를 선택한 뒤 상단의 퍼즐 아이콘을 누른다. 플러그인 창을 열거나 닫아도 그래프와 입력 중인 초안은 유지된다.

- **설치됨**: 현재 워크스페이스에 해당하는 플러그인 이름, 버전, 마켓플레이스, 설치 범위와 활성 상태를 확인한다. Claude CLI가 보고한 오류·주의 사항도 표시한다.
- **마켓플레이스**: Claude에 등록된 마켓플레이스의 플러그인을 이름·설명으로 검색하고 마켓플레이스별로 좁혀 본다. 조회는 저장된 카탈로그를 사용하며, 마켓플레이스 갱신은 사용자가 직접 실행한다.
- 설치 범위는 기본 **이 워크스페이스·나만**(`local`)이다. **프로젝트 공유**(`project`) 또는 **모든 프로젝트**(`user`)도 선택할 수 있다. 프로젝트 공유는 프로젝트의 Claude 설정에 기록된다.
- 설치 버튼은 선택한 플러그인과 범위를 Claude CLI에 전달한다. 성공 후 목록을 다시 조회하며, 실패하면 원인과 다시 시도할 수 있는 상태를 표시한다. 다음 Claude 요청부터 설치된 설정을 사용한다.

## 지원 범위

현재 Mac에 설치된 Claude Code 2.1.268 이상의 플러그인을 관리한다. 원격 워크스페이스는 해당 컴퓨터의 MightyClaude에서 관리한다. 실행 중인 Claude 작업이나 CLI 업데이트·원격 공유와 플러그인 변경이 겹치지 않도록 한다. 진행 중인 변경은 취소할 수 있지만, CLI가 이미 저장한 변경을 되돌리지는 않는다. 취소 후 목록을 다시 읽어 현재 상태를 확인한다.

새 마켓플레이스 등록·플러그인 삭제·활성화 전환은 이번 화면의 범위에 포함되지 않는다. 등록된 마켓플레이스가 없으면 [Claude의 마켓플레이스 추가 방법](https://code.claude.com/docs/en/discover-plugins#add-marketplaces)에 따라 먼저 등록한다. 별도의 명령 실행 동의가 필요한 플러그인은 CLI가 요구한 동의 절차를 따라야 한다.

## 연동

[공식 플러그인 CLI](https://code.claude.com/docs/en/plugins-reference)를 사용한다. `plugin list --json --available`과 `plugin marketplace list --json`으로 조회하고, `plugin install <plugin@marketplace> --scope <scope> --json`으로 설치한다. 앱은 Claude 설정 파일을 직접 편집하지 않는다. 설치 목록의 활성 상태는 CLI의 설정 상태이며, 실행 중인 대화에 이미 로드됐다는 의미는 아니다.
