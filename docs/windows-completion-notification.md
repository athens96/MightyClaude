# Windows Completion Notification

Mirrors the macOS completion notification (AgentCompanion.swift lines 198–213, 346–365).

## OS-bound substitution

`CompletionNotificationStrings.ToggleLabel` reads **작업 완료 시 Windows 알림** where macOS reads **작업 완료 시 Mac 알림** ("Mac" → "Windows"). This is the only divergence from the macOS copy.
