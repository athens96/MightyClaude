# Mac CLI 업데이트

사이드바의 톱니바퀴 **설정 → CLI 업데이트**에서 관리한다.

- **앱 시작 시 CLI 자동 업데이트**를 켜면 다음 앱 시작부터 Claude Code, Codex, Gemini CLI를 차례로 업데이트한다. 기본값은 꺼짐이며 선택은 저장된다.
- **업데이트 하기**는 자동 업데이트 설정과 관계없이 즉시 세 CLI의 업데이트를 시도한다. 진행 중에는 중복 실행하지 않는다.
- 이 Mac에 설치되어 있는 CLI만 대상으로 한다. 원격 컴퓨터의 CLI는 해당 컴퓨터에서 관리한다.
- 설치 방식이 확인되면 그 방식을 유지한다. Claude의 네이티브 설치는 자체 업데이트, Homebrew 설치는 해당 패키지 업그레이드, npm 설치는 기존 설치 prefix의 공식 패키지를 사용한다. 확인할 수 없는 수동 설치나 설치되지 않은 CLI는 이유를 표시하고 건너뛴다.
- npm 시험판은 안정 버전으로 바뀌지 않도록 건너뛴다. 이 경우 기존 시험판 채널에서 직접 업데이트한다. Claude의 자체 업데이트 채널 설정은 유지한다.
- 이 앱에서 해당 CLI로 작업 중이면 그 CLI를 건너뛴다. 원격 공유가 켜져 있을 때는 공유 중인 실행기에 영향을 주지 않도록 업데이트를 건너뛴다. 작업·공유를 마친 후 버튼으로 다시 시도할 수 있다.
- 실패해도 다른 CLI의 업데이트는 계속한다. 각 CLI의 결과와 변경 전후 버전을 표시하며, 완료 후 앱의 버전·모델 정보를 다시 조회한다. `변경 없음`은 설치 관리자를 실행한 뒤 버전이 같다는 뜻이다.

공식 업데이트 방법: [Claude Code](https://code.claude.com/docs/en/setup#update-manually), [Codex CLI](https://learn.chatgpt.com/docs/codex/cli), [Gemini CLI](https://geminicli.com/docs/resources/faq/).

이 기능은 CLI 프로그램을 업데이트한다. MightyClaude 앱 자체의 배포·업데이트 기능과 별개다. Windows 클라이언트의 자동 업데이트 UI는 아직 추가하지 않았다.
