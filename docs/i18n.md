# 다국어 (i18n)

이 문서의 본문은 `node scripts/check-locales.js`가 생성한다. 손으로 고치지 않는다.

## 하나의 원본

`locales/ko.json`과 `locales/en.json`이 저장소의 단 하나의 원본이다. 평평한 의미 키
(`phone.pair.connect` 처럼)에서 문구로 가는 객체이고, 자리표는 `{name}` 꼴이다.
두 파일의 키 집합과 키마다의 자리표 집합은 같다. 한국어 값은 옮기기 전의 리터럴과
바이트까지 같다.

클라이언트는 그 사본을 담는다.

| 클라이언트 | 사본 |
| --- | --- |
| macOS | `native/macos/Sources/MightyCore/Resources/Locales` (`Package.swift`의 `.copy`) |
| Windows | `MightyClaude.WinUI.csproj`의 `Content` 연결 — 뿌리의 파일 자체를 옮기므로 어긋날 수 없다 |
| 전화기 | `mobile/src/locales` (`mobile/src/lib/i18n.ts`가 import) |

`node scripts/check-locales.js`가 사본이 원본과 바이트까지 같은지, 키 집합과 자리표가
맞는지, 쓰이지 않는 키와 없는 키가 없는지를 보고, 하나라도 깨지면 0이 아닌 코드로 끝난다.

## 언어 규칙

전화기는 OS 언어를 따르고 고르는 자리가 없다. OS 언어가 한국어면 한국어를, 그 밖이면
영어를 읽는다. 고른 언어에 없는 키는 한국어 값으로 내려오고, 두 언어에 다 없는 키는
키 자신을 돌려주어 아무것도 깨지지 않는다.

## 영어 초안 — 화면 확인이 필요한 줄

아래 영어는 에이전트가 쓴 초안이다. 화면 확인 때 사람이 한 줄씩 본다.

| 키 | 한국어 | 영어 (초안) |
| --- | --- | --- |
| `phone.hosts.addHost` | + 호스트 추가 | + Add host |
| `phone.hosts.empty.description` | 데스크톱 MightyClaude에서 QR 코드를 띄우고 아래 버튼으로 추가하세요. | Show the QR code in MightyClaude on your desktop, then add it with the button below. |
| `phone.hosts.empty.title` | 페어링된 호스트가 없습니다 | No paired hosts |
| `phone.hosts.reachability.checking` | 확인 중… | Checking… |
| `phone.hosts.reachability.offline` | 호스트 오프라인 | Host offline |
| `phone.hosts.reachability.online` | 연결됨 | Connected |
| `phone.hosts.reachability.relayOffline` | 릴레이 연결 안 됨 | Relay not connected |
| `phone.hosts.reachability.unauthorized` | 재페어링 필요 | Pairing needed again |
| `phone.hosts.reachability.unknown` | 확인 전 | Not checked |
| `phone.hosts.remove.cancel` | 취소 | Cancel |
| `phone.hosts.remove.confirm` | 삭제 | Delete |
| `phone.hosts.remove.message` | {name} 페어링을 삭제할까요? | Delete the pairing with {name}? |
| `phone.hosts.remove.title` | 호스트 삭제 | Delete host |
| `phone.pair.connect` | 연결하기 | Connect |
| `phone.pair.linkHint` | Mac의 설정 → 모바일 리모트에서 페어링 링크를 복사해 붙여넣으세요. | Copy the pairing link from Settings → Mobile remote on your Mac and paste it here. |
| `phone.pair.linkLabel` | 페어링 링크 | Pairing link |
| `phone.pair.mode.manual` | 링크 붙여넣기 | Paste link |
| `phone.pair.mode.qr` | QR 스캔 | Scan QR |
| `phone.pair.paired` | {name} 페어링 완료 | Paired with {name} |
| `phone.pair.permissionAllow` | 카메라 권한 허용 | Allow camera access |
| `phone.pair.permissionChecking` | 카메라 권한을 확인하는 중… | Checking camera permission… |
| `phone.pair.permissionNeeded` | 페어링 QR 코드를 읽으려면 카메라 권한이 필요합니다. | Camera access is required to read the pairing QR code. |
| `phone.pair.qrHint` | Mac의 설정 → 모바일 리모트에서 QR 코드를 띄우고 화면에 맞추세요. | Show the QR code in Settings → Mobile remote on your Mac and line it up on screen. |

## 남은 일

- 언어를 바꾸면 다음 실행 때 적용된다. 그 자리에서 다시 그리는 일은 하지 않았다.
- 표의 남은 문구를 단계마다 한 켜씩 옮긴다. 매니페스트 글과 `styles/**`는 데이터이므로
  옮기지 않는다.
