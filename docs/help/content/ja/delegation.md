エージェント委任では、Claude のペイン(親)が作業を分けて、ほかの Claude のペイン(子)に任せます。子はそれぞれ自分の git worktree で作業し、終わるとレポートを残します。親は通知を受け取ってレポートを読み、結果をマージするかどうかを決めます。Mac アプリだけの機能です。

> [!warning]
> 実験的な機能です。初期状態ではオフで、設定画面もありません。まずは練習用のリポジトリで試してください。

## オンとオフ {#enable}
アプリを終了した状態でターミナルから次のコマンドを実行し、アプリをもう一度開きます。

```sh
defaults write dev.mightyclaude.native delegation.enabled -bool true
```

- オンにすると、Claude のペインで新しい実行を始めるたびに委任ツールが付きます。すでに動いている実行には付きません。
- 親が使うツールは `delegate`(任せる)、`list_children`(子の一覧)、`child_status`(状態とレポート)、`merge`(マージ)、`follow_up`(追加の指示)です。`discard`(破棄)は親には使えず、子のカードからあなただけが行えます。
- オフにするには `defaults delete dev.mightyclaude.native delegation.enabled` を実行します。外れるのはツールだけで、既存の子ペイン、カード、後片付けはそのまま動きます。

## 作業を任せる {#delegate}
1. git リポジトリのフォルダーをワークスペースとして開き、Claude のペインを開きます。このペインが親です。
2. 「この作業を子ペイン二つに分けて任せて」のように頼みます。Claude が `delegate` ツールで子ペインを開きます。
3. 子ペインは親の隣に開き、サイドバーでは親の下に一段下げて表示されます。

![[delegation-tree]]

- 子ごとにブランチ `mighty/<子の id>` と worktree(`~/.mightyclaude/worktrees/<子の id>`)ができます。worktree はプロジェクトフォルダーの外にあるので、親の作業には触れません。
- 任せた作業は TASK.md に、結果は REPORT.md に書かれます。どちらも worktree 内の git が無視するフォルダーにあり、コミットされません。
- 子は親が選んだ権限モードで始まり、そのモードは親のペイン自身のモードより広くできません。広げられるのはあなただけで、実行と実行の合間に、ペインのメニューかスマートフォンの設定から行います。
- 親は子の承認カードに答えられません。子ペインにカードが出たら、そのペインであなたが答えてください。
- 一つの親が開いておける子は 3 つまでで、子はさらに委任できません。ディスクの空きが 10 GB 未満だと委任は断られます。

## 子の状態 {#states}
サイドバーに子ごとの状態が表示されます。

| 状態 | 意味 |
|---|---|
| {{ui:delegation.child.state.creating}} | worktree とペインを作っています。 |
| {{ui:delegation.child.state.running}} | 作業しています。 |
| {{ui:delegation.child.state.waiting}} | 承認や質問へのあなたの答えを待っています。 |
| {{ui:delegation.child.state.reported}} | REPORT.md を残して実行を終えました。 |
| {{ui:delegation.child.state.merged}} | 親のブランチにマージされました。 |
| {{ui:delegation.child.state.ended}} | 新しいレポートなしで実行が終わりました。 |
| {{ui:delegation.child.state.interrupted}} | アプリを終了したため、実行が途切れました。 |
| {{ui:delegation.child.state.failed}} | 子ペインを開始できませんでした。 |

子が新しい実行を始めると{{ui:delegation.child.state.reported}}の状態は外れ、次のレポートには次のレポート番号が付きます。

## 通知と保留 {#notices}
子がレポートしたとき、レポートなしで終わったとき、開始できなかったときに、親へ通知が一度届きます。通知は `[Mighty Claude notice …]` で始まる短い案内にすぎず、レポートの中身は親が `child_status` で読みます。

- 親が実行中なら、通知はその実行にそのまま届きます。
- 親がこのアプリ起動のあとに前の実行を正常に終えて待機しているなら、通知が次の実行を始めます。
- それ以外では通知は保留されます。停止のあと、エラーのあと、アプリを開き直したあと、CLI の更新中などです。

保留された通知は、親の入力欄の上にある待機リストのいちばん上に{{ui:queue.held}}の印付きで表示されます。この行には削除ボタンがありません。

![[delegation-held]]

- 次に何かを送ると、保留された項目がすべて、古い順に、あなたの文より前に付いて一つの実行で届きます。
- {{ui:queue.runNext}}ボタンを押すと、保留された項目だけを一つの実行で送ります。
- 通知はアプリを開き直しても、ちょうど一度だけ届きます。スマートフォンの待機リストにも同じ行が表示され、スマートフォンから送っても一緒に届きます。

## 追加の指示 {#follow-up}
親は `follow_up` ツールで、一つの子に追加の指示を 2 回まで送れます。追加の指示は通知と同じ決まりで子ペインに届き、一つあたり 48 KiB までです。

## マージ {#merge}
子の結果を親のブランチに取り込む方法は二つあります。

1. **親の `merge` ツール**は早送り(fast-forward)だけを行います。親は `child_status` で得た子の head を一緒に渡します。子がまだレポートしていない、コミットしていない変更がある、head が動いた、ブランチが分かれた、または親のブランチがチェックアウトされていない場合は断られ、何も変わりません。このツールで承認カードが出るかどうかは、親のペインの権限モードによります。
2. **カードの{{ui:delegation.card.merge}}ボタン**はあなたが押します。早送りできればそうし、できなければマージコミットをちょうど一つ作ります。先に衝突を調べ、断ったときは理由をカードに表示します。

マージの直後には、カードに{{ui:delegation.card.undo}}ボタンが出ます。親のブランチがそのマージのまま、親のペインが待機中で、コミットしていない変更がないときだけ使えます。取り消すと、ファイルはマージ前の状態に戻ります。

> [!note]
> マージはできたのに委任の記録を保存できなかったときは、カードがそう知らせます。マージはそのままで、記録は次の保存で書き直されます。

## 破棄 {#discard}
カードの{{ui:delegation.card.discard}}ボタンは、子の worktree とブランチを、まだマージしていない作業ごと削除します。破棄できるのはあなただけで、親にはできません。

- 確認ウィンドウ({{ui:delegation.discard.title}})は、子の worktree の中に入っているほかの worktree をすべて示します。
- その一覧を確認できないときは破棄を勧めず、何も止めたり削除したりしません。

> [!tip]
> アプリがまだマージしていない作業を勝手に消すことはありません。マージしていない作業が消えるのは、あなたが確認した破棄のときだけです。

## ペインを閉じる・後片付け {#close}
- **マージ済みの子ペインを閉じると**、作業がすべてマージ済みで未コミットの変更が残っていなければ、アプリが worktree とブランチを片付けます(`git branch -d`、強制削除はしません)。条件に合わなければペインだけが閉じ、worktree は残ります。
- **開いている子がある親のペインを閉じると**、Mac アプリはまず確認します({{ui:delegation.parentClose.title}})。閉じるのは親のペインだけで、子は作業を続けます。
- 親が閉じた子は、サイドバーの{{ui:delegation.tree.parentClosed}}の下にカードとして残ります。その子の通知はカードに保留されて件数が表示され、追加の指示はもう受け取りません。
- 開いている子がある、または片付けていない子の worktree が残っているワークスペースは削除できません。

![[delegation-parent-closed]]

## 上限と対応範囲 {#limits}
| 項目 | 上限 |
|---|---|
| 一つの親が開いておける子 | 3 つ |
| 委任の深さ | 一段(子はさらに委任できない) |
| 一つの子への追加の指示 | 2 回、一つあたり 48 KiB まで |
| 任せる作業(TASK.md) | 64 KiB |
| 必要なディスクの空き | 10 GB |

- 親も子も Claude のペインである必要があります。Codex と Gemini のペインは委任しません。
- Windows アプリにはまだありません。スマートフォンに新しい画面はなく、保留された行が待機リストに表示されるだけです。
