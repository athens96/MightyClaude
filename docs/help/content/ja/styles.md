スタイルは、リクエストの送り方をあらかじめ決めておいた作業の流れです。段階とボタンが用意されているので、長い作業を決まった順序で進められます。スタイルを使わない場合は、これまでどおり自由にリクエストします(CLI)。

## スタイルを選ぶ {#pick}
スタイルは、このMacのClaudeペインでMighty表示のときに使います。
1. Claudeペインを{{ui:graph.view.mighty}}表示に切り替えます。
2. 入力欄の上にあるスタイルメニュー({{ui:guidedPanel.stylesMenuAccessibility}})を開きます。
3. スタイルを選びます。自由なリクエストに戻るには、CLIを選びます。

選択はペインごとに保存されます。実行中は変更できません。スタイルに必要なプラグインやツールがない場合は、{{ui:guidedPanel.installButton}}ボタンが表示されます。クリックすると新しいターミナルペインにインストールコマンドが入力されるので、{{kbd:Enter}}はご自身で押してください。

> [!note]
> 標準スタイルの段階名とボタンは、現在は韓国語でのみ表示されます。

## 標準スタイル {#bundled}
| スタイル | 内容 |
|---|---|
| Ouroboros | インタビューで目標を明確にしてから、シード → 実行 → 評価 → 進化の順に進めます。最初のリクエストがインタビューになります。Ouroborosプラグインと`uvx`が必要です。 |
| Paperthin | 足すよりも削ることに向いた小さなスキルをボタンにまとめています。入力した文章はそのまま送信されます。 |
| Superpowers | ブレインストーミング → 計画 → 実行 → 完了の順に進めます。計画ファイルのチェックボックスを見て、段階と進捗バーが自動的に進みます。 |
| Claudeプラン(클러드 플랜) | 新しいリクエストのたびに、Claudeの計画モードで始まります。計画カードを承認すると実行します。チェックリストの進捗とバックグラウンドタスクがウィジェットで表示されます。 |

## 計画カード {#plan-card}
Claudeが計画モード(Plan mode、またはClaudeプランのスタイル)で計画を終えると、計画カードが表示されます。

![[plan-card]]

1. 計画を読みます。{{ui:plan.card.expand}}をクリックすると、ドキュメントのように大きく表示されます。
2. 次のいずれかを選びます。
   - {{ui:plan.card.approveAuto}}: 承認し、ファイルの変更は確認なしで進めます。
   - {{ui:plan.card.approveConfirm}}: 承認し、操作ごとに確認を求めます。
   - {{ui:plan.card.revise}}: 変更点を書いて{{ui:plan.card.reviseSend}}をクリックすると、Claudeが計画を立て直します。
   - {{ui:plan.card.cancel}}: 計画を却下し、今回の作業を止めます。

Mightyダイアグラムでは、計画はリクエストの下のブロックに表示され、4つの回答は入力欄の側(スタイルを使っている場合はスタイルのパネル)に並びます。計画ブロックは結果カードと同じようにウインドウのサイズに合わせて表示され、サイズを手動で変更した場合は{{ui:graph.result.fitToWindow}}ボタンが表示されます。標準表示とタイムラインでは、計画と回答が1枚のカードにまとまって入力欄の上に表示されます。

デスクトップペットにも完成した計画が表示されます。受け取った時刻、計画の最初の数行、回答ボタンが並びます。ペット上でそのまま{{ui:plan.card.approveAuto}}や{{ui:plan.card.cancel}}をクリックできます。変更をリクエストしたり計画全体を読んだりするには、{{ui:companion.plan.review}}（Macでは{{ui:plan.card.revise}}も）をクリックします。4つの回答がそろった小さなウィンドウに計画が開き、計画に回答するとウィンドウは閉じます。

回答した計画は履歴に残り、あとで見直せます。

## ほかのスタイルを追加する {#custom}
標準スタイルのほかに、ファイルで定義されたスタイルも使えます。
1. {{ui:menu.settings}} → {{ui:settings.nav.styles}}で{{ui:settings.styles.registerButton}}をクリックします。リポジトリの`.claude/mighty-styles/`内のスタイルは自動的に検出されます。一覧が正しくない場合は{{ui:settings.styles.rescanButton}}をクリックします。
2. 新しいスタイルは、最初に一度内容を確認する必要があります。{{ui:settings.styles.viewButton}}ボタンで、提供元、自動で許可するツール、インストールコマンド、すべてのボタンを確認します。
3. 問題がなければ{{ui:settings.styles.allowButton}}をクリックします。

スタイルのファイルが変更されると、再度確認が必要になります。許可を取り消すには、同じ場所の{{ui:settings.styles.revokeButton}}をクリックします。

> [!warning]
> ツールを自動で許可するスタイルは、そのツールを確認なしで実行します。提供元が信頼できる場合にのみ許可してください。
