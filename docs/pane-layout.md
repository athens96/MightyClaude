# 실행 창의 탭과 분할 배치

Mac에서는 한 앱 창 안에서 워크스페이스마다 하나의 배치 영역을 가진다. 각 분할 영역은 여러 탭을 담을 수 있으며, 탭과 분할을 동시에 사용한다. 워크스페이스 오른쪽의 `+`에서 종류를 선택하면 현재 그룹의 탭으로 추가한다. 탭 줄에는 추가·분할 버튼을 중복 배치하지 않는다. 이름은 탭에 한 번만 표시하며 내용 위에는 실행 시간·상태·메뉴를 둔다. 탭의 이름 부분을 잡고 같은 워크스페이스 안의 다른 영역으로 드래그한다.

- 가운데에 놓으면 해당 영역의 탭으로 합친다.
- 왼쪽·오른쪽·위·아래 가장자리에 놓으면 그 방향으로 분할한다.
- 탭 위에 놓으면 탭 순서를 바꾼다.
- 두 영역 사이의 분할선을 드래그하면 크기를 조절한다.
- 집중 보기는 선택한 실행 창을 크게 보여준다. 배치 변경은 탭 드래그로 한다.

배치와 집중 보기 여부, 마지막 선택한 탭은 워크스페이스별로 저장된다. 워크스페이스를 전환해도 다른 워크스페이스의 집중 보기 설정을 덮어쓰지 않는다. 실행 창을 닫으면 빈 탭 그룹과 불필요한 분할이 정리된다. 사이드바에서 실행 창을 선택하면 해당 그룹의 탭도 선택된다.

이동은 실행 창의 배치만 바꾼다. 대화와 실행 설정, 작성 중인 초안·첨부, 실행 중인 작업은 같은 세션에 남는다. Mac의 Ghostty 터미널은 기존 네이티브 화면과 셸을 유지한다. 탭의 네이티브 마우스 추적은 출력 선택 및 입력창의 파일·이미지 드롭과 독립적이다. 드래그 중 배치 미리보기가 나타나며 Esc 또는 창 밖 드롭은 이동을 취소한다.

## 제목줄과 이름 변경

워크스페이스 제목줄의 제목 또는 빈 공간을 두 번 클릭하면 Mac 창을 확대하고, 다시 두 번 클릭하면 이전 크기로 복원한다. 같은 영역을 끌면 창을 이동한다. 경로 선택과 창 추가 버튼은 각자의 기존 동작을 유지한다. 상단의 별도 원격 연결 도구 모음은 제거했으며, 사이드바 설정의 **원격 연결 → Tailscale 원격 연결 설정**에서 연결·공유를 관리한다.

로컬 Git 워크스페이스는 제목줄에 브랜치, 커밋하지 않은 변경 표시, 로컬 upstream 기준 앞섬·뒤처짐을 표시한다. 활성 워크스페이스에서 10초마다 읽기 전용으로 갱신하며 원격 fetch는 하지 않는다. 원격 워크스페이스의 Git 정보는 아직 표시하지 않는다.

사이드바의 워크스페이스·실행 창, 또는 탭에서 우클릭해 **이름 변경…**을 선택한다. 탭은 두 번 클릭해도 이름을 바꿀 수 있다. 변경한 이름은 저장되며 실제 폴더 경로, 세션 ID, 대화와 초안에는 영향을 주지 않는다.

## 저장 데이터

네이티브 상태 파일의 선택 필드 `paneLayouts`가 워크스페이스 ID별 배치 트리를 저장한다. `tabs` 노드는 세션 ID의 순서와 선택한 탭을, `split` 노드는 방향·비율·두 자식 영역을 가진다. 예전 파일에 이 필드가 없으면 기존 배치를 기반으로 시작한다. 로드할 때 닫힌 세션·잘못된 참조·중복을 제거하고 새 세션을 추가한다. 분할 깊이와 노드 수, 비율도 제한한다.

Mac의 선택 필드 `paneLayoutModes`와 `paneLayoutActiveSessionIds`는 각각 워크스페이스별 보기 모드와 마지막 선택 세션을 저장한다. 이전 전역 `layout` 값은 기존 파일을 불러올 때만 참고한다. 다른 워크스페이스의 세션을 가리키거나 잘못된 모드인 항목은 정규화한다. Windows는 기존 배치 구현을 유지한다.

Mac 통합 검사는 새 임시 프로필로 실행한다.

```sh
release/native-macos/MightyClaude.app/Contents/MacOS/MightyClaude \
  --layout-smoke-test --smoke-exit --profile /tmp/mighty-layout-smoke
```

`layout-smoke-result.json`과 실제 창 이미지를 프로필 폴더에 저장한다. 실제 창의 hit test와 NSWindow 마우스 이벤트를 통해 탭 합치기·분할·순서 변경·취소 및 드롭 전 미리보기를 검사한다. 이는 네이티브 합성 이벤트 검사이며 물리 마우스 장치 입력은 아니다. 실제 Ghostty PTY 유지, 초안·첨부 보존, 저장·복원도 검사하고 AI 요청은 전송하지 않는다.
