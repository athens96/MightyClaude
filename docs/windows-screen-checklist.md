# Windows 기기 화면 점검 체크리스트

단계별로 Windows 기기에서 직접 확인해야 할 항목. macOS를 기준으로 동작을 대조한다.
각 항목은 CI 스모크 테스트가 검증할 수 없는 시각·조작적 확인이다.

---

## 스모크 테스트 (모든 빌드 공통)

빌드마다 `--smoke-test` 플래그로 WinUI를 기동하고 `smoke-result.json`을 확인한다.
스크린샷이 `artifacts/smoke/*.png`에 저장되면 아래를 눈으로 점검한다.

- [ ] 앱이 1440×920 창으로 열린다
- [ ] 좌측 사이드바에 MightyClaude 로고와 제목이 표시된다
- [ ] "워크스페이스 검색" 입력란이 있다
- [ ] "+ 프로젝트 폴더" 버튼이 있다
- [ ] "원격 연결", "설정" 버튼이 하단에 있다
- [ ] 레이아웃 드롭다운(격자/나란히/집중/탭/사용자 배치)이 있다
- [ ] 하단 상태 텍스트가 비어 있거나 정상 메시지다(오렌지 오류 텍스트 없음)

## 이미 있음 — 출시 전 회귀 점검

아래 기능은 현재 구현된 상태이므로 각 릴리스에서 회귀하지 않는지 확인한다.

### 실행 창 레이아웃
- [ ] 격자 레이아웃: 창이 격자로 배치된다
- [ ] 나란히 레이아웃: 창이 좌우로 배치된다
- [ ] 집중 레이아웃: 창 하나만 표시된다
- [ ] 탭 레이아웃: 탭 방식으로 전환된다

### 에이전트 필기록
- [ ] 실행 중 모델 출력이 순서대로 표시된다
- [ ] 코드 블록이 고정폭 글꼴로 렌더링된다

### 파일 첨부
- [ ] 파일 선택 후 첨부 목록에 파일명이 나타난다
- [ ] 첨부 파일이 실행 요청에 포함된다

### 세션 컨텍스트 사용량
- [ ] 컨텍스트 버튼 또는 표시 영역이 보인다
- [ ] 사용 비율이 실시간으로 갱신된다

### 권한 모드
- [ ] 실행 설정에서 권한 모드 선택이 가능하다
- [ ] 자동 허용 모드에서 도구 호출이 승인 없이 진행된다

### 원격 워크스페이스
- [ ] "원격 연결" 버튼을 누르면 연결 UI가 열린다
- [ ] 원격 서버 주소를 입력하면 연결을 시도한다

### IME 조합 처리
- [ ] 한글 IME를 사용할 때 조합 중 Enter가 실행을 트리거하지 않는다
- [ ] 조합 완료 후 Enter가 정상 전송된다

## 1단계 점검

각 기능을 구현한 뒤 Windows 기기에서 확인한다.

### 슬래시 명령 완성

<!-- 기기 미확인 -->

- [ ] 입력창에 `/`를 입력하면 팔레트가 열린다 (기기 미확인)
- [ ] 입력을 이어 쓰면 목록이 필터링된다 (기기 미확인)
- [ ] 항목을 선택하면 명령이 입력창에 삽입된다 (기기 미확인)
- [ ] `Esc`를 누르면 팔레트가 닫히고 초안은 그대로 남는다 (기기 미확인)
- [ ] 각 줄이 `/이름`(고정폭 반굵게)·설명(없으면 `설명 없음`)·출처 배지 순서로 보인다 (기기 미확인)
- [ ] 앱에서 바로 실행되는 명령에는 `↵`, 인수를 이어 고르는 명령에는 `›` 표식과 툴팁이 보인다 (기기 미확인)
- [ ] 푸터에 `↑↓ 이동 / Enter · Tab 선택 / Esc 닫기`와 `{개수}개`가 보인다 (기기 미확인)
- [ ] 목록이 8줄을 넘으면 스크롤되고 강조된 줄이 화면 안으로 따라온다 (기기 미확인)
- [ ] `↑`·`↓`가 강조를 옮기고 처음·끝에서 반대쪽으로 넘어간다 (기기 미확인)
- [ ] 마우스를 올리면 그 줄이 강조되고, 클릭하면 선택된다 (기기 미확인)
- [ ] 팔레트가 열려 있을 때 `Enter`·`Tab`이 요청을 보내지 않고 선택만 한다 (기기 미확인)
- [ ] `/model`·`/permissions`를 고르면 모델·권한 선택이 이어서 열린다 (기기 미확인)
- [ ] 앱 명령(`/clear`·`/cost`·`/config`·`/rename`·`/help`)은 실행되고 초안이 비워진다 (기기 미확인)
- [ ] 팔레트가 닫혀 있으면 한글 조합과 `Shift+Enter`가 이전과 똑같이 동작한다 (기기 미확인)

### 상태 표시줄

<!-- 기기 미확인 -->

- [ ] 창 하단 또는 상단에 상태 표시줄이 있다 (기기 미확인)
- [ ] 실행 중 상태(예: "실행 중…")가 표시된다 (기기 미확인)
- [ ] 실행 완료 후 상태가 갱신된다 (기기 미확인)

#### Claude 상태 줄 (`statusLine`)
- [ ] `~/.claude/settings.json`의 `statusLine` 출력이 입력창 바로 아래에 그려진다 (기기 미확인)
- [ ] 명령이 낸 색과 굵기가 그대로 보이고, 7줄 이상 출력해도 6줄까지만 그려진다 (기기 미확인)
- [ ] 저장소의 `.claude/settings.json`에 `statusLine`이 있으면 먼저 "…에 statusLine 명령이 있습니다. 이 워크스페이스에서 실행할까요?" 질문과 두 버튼이 보인다 (기기 미확인)
- [ ] "이 워크스페이스에서 허용"을 누르기 전에는 그 명령이 실행되지 않는다 (기기 미확인)
- [ ] 저장소가 명령을 바꾸면 다시 묻는다 (기기 미확인)
- [ ] 멈춘 명령(예: `sleep 60`)을 넣어도 8초 뒤 정리되고 창이 멈추지 않는다 (기기 미확인)

### CLI 계정 전환
- [ ] 설정 화면에서 연결된 CLI 계정 목록이 표시된다
- [ ] 계정을 선택하면 활성 계정이 전환된다
- [ ] 토큰·자격증명은 화면에 노출되지 않고 레이블만 표시된다
- [ ] 로그아웃 후 계정이 목록에서 제거된다

### 계정 사용량 표시
- [ ] 계정별 사용량이 기본 숨김 상태로 설정에 있다
- [ ] 사용량 표시를 켜면 수치가 나타난다

### CLI 업데이트
- [ ] 설정 화면에 CLI 업데이트 섹션이 있다
- [ ] 업데이트 확인 버튼을 누르면 확인 중 상태가 표시된다
- [ ] 업데이트 가능 시 버전 정보와 업데이트 버튼이 표시된다

### 앱 자체 업데이트
- [ ] 설정 화면에 앱 업데이트 섹션이 있다
- [ ] 최신 버전 확인이 `latest.json`의 `windows.x64` 또는 `windows.arm64` 블록을 참조한다
- [ ] 업데이트 가능 시 버전 정보와 다운로드·설치 안내가 표시된다

### 세션·창 이름 변경
- [ ] 세션 항목을 길게 누르거나 컨텍스트 메뉴에서 이름 변경이 가능하다
- [ ] 이름 입력 후 확인하면 사이드바 목록에 반영된다
- [ ] 실행 창도 동일한 방식으로 이름을 바꿀 수 있다

### Claude 플러그인 목록
- [ ] 설정 화면에 플러그인 섹션이 있다
- [ ] 감지된 Claude 플러그인이 목록에 표시된다
- [ ] 플러그인 활성화·비활성화가 가능하다

### Codex 플러그인
- [ ] Codex 플러그인이 설치된 경우 플러그인 목록에 나타난다
- [ ] Codex 실행 시 플러그인이 인식된다

### 설정 화면 (전체)
- [ ] 설정 화면이 별도 창 또는 다이얼로그로 열린다
- [ ] 계정, 업데이트, 컴포넌트, 스타일 섹션이 있다
- [ ] 각 섹션이 올바른 내용을 표시한다
- [ ] 설정 저장 후 앱을 재시작해도 설정이 유지된다

### Claude 추가 권한 요청의 앱 내 승인
- [ ] 자동 허용 밖의 도구를 Claude가 요청하면 실행 창에 승인 막대가 뜨고, 요청한 도구 이름과 입력이 전부 보인다
- [ ] 허용·거부를 누르면 실행이 그 결정대로 이어지고, 같은 요청이 두 번 뜨지 않는다
- [ ] 원격 세션과 Codex·Gemini 실행에서는 승인 막대가 뜨지 않는다(macOS와 같은 범위)
- [ ] (기기 미확인) 승인 막대에 도구 제목·요약·이유·접근 경로가 보이고, 여러 개가 기다리면 `N개 대기`가 보인다
- [ ] (기기 미확인) `이번만 허용`은 그 호출 하나만 통과시키고 다음 요청은 다시 묻는다
- [ ] (기기 미확인) 설문형 요청(`AskUserQuestion`)은 허용 버튼 없이 `거부`만 보인다
- [ ] (기기 미확인) 실행을 중지하면 기다리던 승인 막대가 모두 사라진다

- [ ] 설정 화면에 스타일 섹션이 있다
- [ ] 스타일 매니페스트를 불러오면 항목이 표시된다
- [ ] 스타일 승인 시트가 열리고 승인·거부가 가능하다

### 가이드 패널
- [ ] 실행 중 에이전트 질문이 별도 패널에 표시된다
- [ ] 답변 입력 후 에이전트가 계속 진행한다

### 실행 그래프
- [ ] 실행 그래프 뷰가 열린다
- [ ] 노드와 엣지가 렌더링된다
- [ ] 노드 선택 시 세부 정보가 표시된다

### 컴포넌트 (설치 대시보드)
- [ ] 컴포넌트 설정 화면에서 설치된 컴포넌트 목록이 보인다
- [ ] 컴포넌트 상태(설치됨/미설치/업데이트 가능)가 표시된다

### 워크스페이스 Git 정보
- [ ] Git 저장소 워크스페이스에서 현재 브랜치와 상태가 표시된다

### 컨텍스트 압축 표시
- [ ] 컨텍스트 압축 이벤트 발생 시 UI에 표시된다

### 그래프 블록 크기 조정
- [ ] 실행 그래프에서 블록 크기를 조정할 수 있다

### 참조 링크 버블
- [ ] 실행 그래프에서 참조 링크가 버블로 표시된다
- [ ] 버블을 클릭하면 링크가 열린다

### 세션 템플릿
- [ ] 세션을 템플릿으로 저장할 수 있다
- [ ] 저장된 템플릿으로 새 세션을 시작할 수 있다

- [ ] 설치·제거 뒤 슬래시 명령 자동완성과 플러그인 목록이 바로 갱신된다

## 3단계 점검

### 동반 펫
- [ ] 펫이 화면 모서리 또는 지정 위치에 표시된다
- [ ] 펫 종류를 선택할 수 있다
- [ ] 펫이 실행 상태에 반응한다

### 모바일 릴레이 호스트
- [ ] Windows 앱이 릴레이 서버 호스트로 동작한다
- [ ] 모바일 앱에서 연결 후 실행이 가능하다

### 사용자 설문
- [ ] 초기 설정 시 설문 화면이 표시된다
- [ ] 설문 응답이 저장된다

---

### 완료 알림
- [ ] 앱이 뒤에 있을 때 실행이 끝나면 Windows 알림(토스트)이 한 번 뜨고, 누르면 해당 실행 창으로 이동한다
- [ ] 앱이 앞에 있을 때는 알림이 뜨지 않는다

### CLI 업데이트 (기기 미확인)
- [ ] winget으로 설치한 CLI가 `winget` 방식으로 표시되고, 업데이트 시 그 패키지 하나만 올라간다
- [ ] npm 전역 설치 CLI가 `npm` 방식으로 표시되고, 업데이트 시 공식 패키지만 올라간다
- [ ] 네이티브 Claude Code 설치가 `native`로 표시되고 `claude update`로 갱신된다
- [ ] 업데이트 중 권한 상승(UAC) 창이 뜨지 않는다
- [ ] 업데이트 중 취소를 누르면 설치 프로그램과 그 자식 프로세스가 모두 멈춘다
- [ ] 시험판 npm 채널이 `건너뜀`으로 표시되고 버전이 바뀌지 않는다

### 계정 사용량 표시
- [ ] 로컬 AI 실행 창이 있는 실행기마다 하단 상태 줄에 칩이 하나씩 보인다
- [ ] `shell` 실행 창만 있거나 원격 워크스페이스만 있으면 칩이 없다
- [ ] 아무것도 켜지 않은 상태에서 Claude 칩이 `실행 후 표시`로 보인다
- [ ] Claude를 한 번 실행하면 CLI가 보고한 세션·주간 한도가 칩과 팝오버에 나타난다
- [ ] Codex에 로그인되어 있으면 칩에 세션·주간 사용률이 보인다
- [ ] Gemini 카드에 `/stats`를 안내하는 문장이 보인다
- [ ] 칩을 누르면 팝오버에 창별 사용률·진행 막대·초기화 시각·마지막 확인 시각이 보인다
- [ ] 새로고침 버튼을 누르는 동안 창이 멈추지 않는다
- [ ] 직접 조회 스위치를 켜면 Claude 한도가 채워지고, 끄면 조회로 받은 값이 사라진다
- [ ] 직접 조회를 켠 채 앱을 다시 켜면 스위치가 켜진 상태로 남는다
- [ ] 네트워크를 끊고 새로고침하면 마지막 값이 `마지막 확인값 · `과 함께 남는다
- [ ] 조회 중에 창을 닫으면 앱이 바로 종료된다
- [ ] 조회 전후로 `%USERPROFILE%\.claude\.credentials.json`의 내용과 수정 시각이 그대로다

## 배포 인프라 점검
